# Aerostat
This repository will contain the latest project progress

## STEPS TO BE FOLLOWED

1. Open folder `aerostat_localserver` and open `cmd prompt` on this directory.
2. Type `python backend.py` and press `Enter`.
3. After that, open `aerostat_webapp` folder and open `cmd prompt` on this directory.
4. Type `npm install` then `npm run dev`.
5. A local host url will be provided, open it by `CTRL+CLICK` & your Web Application will be started.
6. First click on the config button, and enter your ip and ports. Select Save & the values will start updating.

## INSTALLATIONS
### Nodejs:

1. Download Node.js:

Go to the [Node.js official website](https://nodejs.org/en).                  
Download the latest LTS (Long Term Support) version for Windows (usually the Windows Installer).

2. Install Node.js:

Run the installer you downloaded.
Follow the installation prompts. Ensure that the option to install npm is checked.
The installer will automatically add Node.js and npm to your system's PATH.

3. Verify Installation:

Open Command Prompt (search for cmd in the Start menu).
Run node --version to check the Node.js version.
Run npm --version to check the npm version.

### Python:
1. Download Python:

Go to the [Python official website](https://www.python.org/downloads/).                        
Download the latest version of Python for Windows (usually the executable installer).

2. Install Python:

Run the installer.
Check the box that says "Add Python to PATH" before clicking "Install Now."
Follow the prompts to complete the installation.

3. Verify Installation:

Open Command Prompt (search for cmd in the Start menu).
Run python --version to check the Python version.
Run pip --version to check if pip is installed.
